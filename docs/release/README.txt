hwpx2hwp 1.0.0
==============

hwpx 문서를 hwp 문서로 한꺼번에 바꿔 주는 Windows 프로그램입니다.
변환은 PC에 설치된 한/글이 합니다.

필요한 것
---------
- Windows 10 또는 11 (64비트)
- 한/글 2014 이상 설치
- .NET 설치는 필요 없습니다(hwpx2hwp.exe 하나로 실행).

사용법
------
1. hwpx2hwp.exe 를 실행합니다.
2. hwpx 파일이나 폴더를 창에 끌어다 놓거나 [파일 추가]·[폴더 추가]를 누릅니다.
   폴더는 하위 폴더까지 찾습니다.
3. 출력 폴더를 고릅니다([찾아보기]). 고르지 않거나 [기본으로]를 누르면 원본과 같은 폴더에 저장합니다.
   출력 폴더를 고르면 폴더 입력의 하위 구조를 그대로 만듭니다.
4. [변환]을 누릅니다. 진행 중에 [취소]를 누르면 지금 파일까지만 하고 멈춥니다.
5. 끝나면 성공·실패 개수가 나옵니다. [로그 열기]로 자세한 내용을 봅니다.
   다시 [변환]을 누르면 아직 성공하지 않은 파일만 다시 변환합니다.

알아 둘 것
----------
- 원본 hwpx 는 바꾸거나 지우지 않습니다.
- 같은 이름의 hwp 가 이미 있으면 덮어쓰지 않고 이름_1.hwp, 이름_2.hwp … 로 저장합니다.
- 암호가 걸린 문서는 변환하지 않고 실패(이유: 암호)로 표시합니다.
- 한/글이 파일 접근 승인 창을 띄울 수 있습니다. 허용을 누르면 계속됩니다.
- 프로그램은 한 번에 하나만 실행됩니다. 다시 실행하면 이미 열린 창이 앞으로 옵니다.
- 로그 위치: %LOCALAPPDATA%\hwpx2hwp\logs\
- 다운로드 폴더처럼 여러 사람이 파일을 넣을 수 있는 폴더가 아닌, 본인만 쓰는 폴더에 두고 실행하세요.
